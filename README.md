# Portfolio — Illona Saboundjian

Mon portfolio de développeuse Full Stack. Il présente mon parcours et mes projets.

🔗 **Démo :** [portfolio-is-phi.vercel.app](https://portfolio-is-phi.vercel.app)

## 🛠️ Stack

- **Framework :** Next.js 16 (App Router)
- **UI :** React 19, Tailwind CSS 4, Lucide React
- **Langage :** TypeScript
- **Qualité :** ESLint
- **Déploiement :** Vercel

## 🚀 Lancer le projet

Prérequis : Node.js 20 ou plus.

```bash
git clone https://github.com/IllonaSab/Portfolio_IS.git
cd Portfolio_IS
npm install
npm run dev
```

Ouvre [http://localhost:3000](http://localhost:3000).

## 📜 Scripts

| Commande | Action |
| --- | --- |
| `npm run dev` | Serveur de développement |
| `npm run build` | Build de production |
| `npm run start` | Lance le build de production |
| `npm run lint` | Vérifie le code avec ESLint |
